# Data: features and token history

Generated by `scripts/report_data.py` from the feature and token Parquet files and the stage reports (data config hash `1470391126a4`). Rerun after any data change.

## 1. Aggregate features (the classical models' inputs)

1,824 snapshots (one per trading day at 15:15) × 40 features. Definitions are in `docs/schema.md`.

![Feature coverage](../outputs/reports/figures/data_feature_coverage.png)

Gaps follow known source issues: **missing_option_oi**: GEX, levels, PCR and OI-change features are missing on missing_option_oi days (2019-07-30, 2022-01-03..2022-04-11); **oi_change**: OI change also needs the previous day's EOD OI, so the first day after a missing-OI block is missing too; **vix**: daily VIX ends 2026-04-06; later rows have vix_previous_close missing (never forward-filled); **participant**: participant OI covers all index options, not NIFTY only.

![Key features](../outputs/reports/figures/data_key_features.png)
