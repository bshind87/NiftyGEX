# Provenance

The legacy project `nifty-options-feature` (local copy at `/Users/bhalchandra/myPythonCode/nifty-options-feature`) was co-developed by Sunil Kandakur and Bhalchandra. Its repository is authored under Sunil Kandakur's name. The files below are adapted from it for this CS 7150 course project with his permission.

Legacy paths are relative to the legacy project root. Files in this repository that are not listed here are new implementations written for NiftyGEX, for example `clean/dedup.py`, `clean/quality.py`, `clean/basis.py`, `io/calendar.py`, `io/availability.py`, `io/parquet.py`, `io/regimes.py`, `exposure/*`, `features/aggregate.py`, `targets/vol_regime.py`, `targets/intraday_drift.py`, `features/tokens.py`, `features/realized_vol.py`, `scripts/compute_tokens.py`, `scripts/run_t2_ablation.py`, `scripts/write_findings_t2.py`, `scripts/run_t3_placebo.py`, `validation/*`, the whole evaluation layer `src/niftygex_eval/` with `scripts/run_stage_a.py` and `run_stage_b.py`, `pricing/greeks.py`, `scripts/compute_basis.py`, `compute_greeks.py`, `compute_gex.py`, `compute_features.py`, `compute_targets.py`, `validate_data.py`, and all tests.
